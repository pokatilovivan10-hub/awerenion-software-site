# 27 Technologies — сайт (демоверсия для согласования)

Корпоративный адаптивный сайт компании 27 Technologies (ООО «СКС»).

## Страницы
- `index.html` — главная
- `software.html` — заказная разработка ПО
- `web-services.html` — веб-сервисы и сложные сайты
- `cases.html` — направления для будущих кейсов
- `about.html` — о компании и контакты
- `privacy.html` — заглушка для утверждённой политики обработки персональных данных
- `404.html` — страница ошибки

## Как посмотреть
Распаковать архив и открыть `index.html` в браузере. Для полноценной проверки форм нужно разместить сайт на хостинге (например, Netlify). Дизайн и навигация работают локально.

## Что необходимо получить до боевого запуска
1. Утверждённые сведения о компании и реквизиты ООО «СКС», фирменный логотип и визуальные материалы (если имеются).
2. Минимум три реальных кейса с подтверждённой задачей, функционалом, технологиями и результатом. Сейчас раздел «Кейсы» содержит **не кейсы**, а помеченные направления будущего портфолио.
3. Подтверждённый технологический стек; описание команды и опыта; конкретные коммерческие условия только после согласования.
4. Утверждённую политику обработки персональных данных, сведения об операторе и согласие для форм. Текущая `privacy.html` — намеренная заглушка, не готовый правовой документ.
5. ID счётчика Яндекс Метрики. В HTML предусмотрена переменная `window.METRIKA_ID`, а в JS — цели `submit_form`, `click_phone`, `click_email`, `click_messenger`. Нужно добавить официальный код Метрики, указать ID и проверить тестовые цели.
6. Почту или сервис для отправки заявок. Формы подготовлены для Netlify Forms (после публикации на Netlify необходимо настроить e-mail-уведомления); на другом хостинге следует подключить обработчик форм. Локально отправка отключена.
7. Домен, хостинг, HTTPS, согласование контента и финальное тестирование на устройствах/браузерах.
